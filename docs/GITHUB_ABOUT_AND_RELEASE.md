# Suggested GitHub metadata

**Repository name:** `PG-JMADKFC-Metabolomics`

**Description:** Research code and reproducibility materials for prototype-guided deep kernel fuzzy clustering of incomplete metabolomics data.

**Topics:** `fuzzy-clustering`, `metabolomics`, `missing-data`, `deep-clustering`, `adaptive-kernel`, `reproducible-research`

**Proposed release title:** `v1.0.0 — PG-JMADKFC Scientific Reports revision research package`

**Release body:**

This research package contains the source implementation of PG-JMADKFC, eleven benchmark baseline implementations, code for MAR/MNAR/MCAR simulation, observed-only normalization, model fitting, reviewer-requested ablations, missing-entry completion comparisons, statistical analyses and feature perturbation. Archived 2,160 main benchmark fit summaries and additional experiment records are included. Participant-level data are excluded from the public release, with original dataset citations and preparation instructions under `data/README.md`. Please consult `docs/REPRODUCIBILITY_AUDIT.md` for a fresh-replay discrepancy on one PG fit; do not represent the results as exact independently reproduced solely on the basis of archived numerical integrity checks.
