\subsection*{Code Availability}
The Python implementation of PG-JMADKFC, the eleven baseline implementations used in the main benchmark, the experimental configuration files, the scripts for dataset preparation and missingness simulation, and the code for component ablation, missing-entry completion, statistical analysis, and metabolite-level interpretation are publicly available at \url{https://github.com/USERNAME/REPOSITORY}. The repository includes the per-fit benchmark outputs, aggregated results, reproducibility instructions, and numerical integrity checks. The experimental analyses use three publicly available metabolomics datasets (MTBLS161, MTBLS404, and Human Cachexia); source-data access and preparation procedures are documented in the repository. Repository release: \url{https://github.com/USERNAME/REPOSITORY/releases/tag/v1.0.0}.
