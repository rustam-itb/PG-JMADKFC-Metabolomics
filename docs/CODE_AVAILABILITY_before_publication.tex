\subsection*{Code Availability}
The Python implementation of PG-JMADKFC, the eleven baseline implementations, and all scripts used for the main benchmark and reviewer-requested additional experiments have been organized into a reproducibility package. The package includes configuration files, result-level checks, and documentation for accessing and preparing the source datasets.
